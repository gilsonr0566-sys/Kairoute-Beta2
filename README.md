# Kairoute Beta 2

A second copy of the Kairoute app whose trip plans come from the new planning engine (Beta 2), published beside the
main app so both can be compared. Built from the Kairoute repository (branch with the Beta 2 engine) by
`build-beta2.sh`; this repository only holds the built files. It keeps its own saved data (it copies the main app's
trips in once, read only) and never changes what the main app has saved.

Live: https://gilsonr0566-sys.github.io/Kairoute-Beta2/
